# Playwright Automation Testing Project

## About
Automated end-to-end testing project built using Playwright.

## Tech Stack
- Playwright
- JavaScript
- Node.js

## Test Scenarios
- User Login
- User Logout
- User Signup
- Listing creation
- Listing editing
- Listing deletion
- Search functionality

## How to Run

npm install

npx playwright install

npx playwright test

## View HTML Report

npx playwright show-report
